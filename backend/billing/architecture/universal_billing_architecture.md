# Purpose

The Universal Billing Architecture (UBA) is the canonical billing architecture for LinkCraftor.

It provides a centralized billing platform responsible for:

- Pricing
- Product catalog
- Subscription management
- Usage metering
- Action Unit (AU) accounting
- Document billing
- API billing
- Invoice generation
- Payment processing
- Taxation
- Revenue operations
- Enterprise billing
- OEM licensing
- Marketplace billing

No product or subsystem may implement independent billing logic outside this architecture.
