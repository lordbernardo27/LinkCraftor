# Service Registry

**Version:** 1.0.1
**Status:** Canonical
**Architecture Phase:** 2.1.2
**Last Updated:** 2026-09-05

---

# Purpose

The Service Registry is the canonical registry for every billable and non-billable service provided by LinkCraftor.

Every platform service shall be uniquely registered before it can participate in billing, subscriptions, APIs, enterprise offerings or marketplace products.

---

# Registry Objectives

- Single Canonical Service Registry
- Unique Service Identification
- Service Discoverability
- Product-Service Mapping
- Billing Integration
- API Integration
- Runtime Traceability
- Version Control
- Lifecycle Management

---

# Registered Service Categories

- Core Platform Services
- Internal Linking Services
- Semantic Linking Services
- External Linking Services
- AI Processing Services
- Batch Processing Services
- API Services
- Enterprise Services
- OEM Services
- Marketplace Services
- Future Services

---

# Service Requirements

Every registered service shall include:

- Service ID
- Service Name
- Service Category
- Service Description
- Owning Product
- Billing Eligibility
- Pricing Association
- Feature Association
- Version
- Status
- Availability
- Effective Date
- Retirement Date (if applicable)
