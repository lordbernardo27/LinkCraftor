# LinkCraftor WordPress Plugin Version Policy

Plugin Version
0.1.0

Version Format
MAJOR.MINOR.PATCH

MAJOR
Breaking plugin architecture, public contract, or compatibility change.

MINOR
Backward-compatible functionality or substantial capability addition.

PATCH
Backward-compatible bug fix, security fix, or internal correction.

Minimum WordPress
6.9

Minimum PHP
8.3

LinkCraftor Protocol Compatibility
1.0

Protocol Rule
Plugin releases may advance independently of the LinkCraftor protocol.
A protocol-major change requires explicit compatibility handling before release.
