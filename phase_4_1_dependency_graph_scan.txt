================================================================================
SECTION 1 — PHASE 4.1 PURPOSE
================================================================================

Phase 4.1 defines the canonical structural dependency topology used by the
Universal Coordination Framework.

It answers:

    Which stages exist in the graph?

    Which stages are prerequisites of other stages?

    Which stages depend on a particular stage?

    Which stages are structural roots?

    Which stages are structural leaves?

It does NOT determine whether a stage can execute now.

It does NOT execute a stage.

It does NOT produce a Runtime job.

It does NOT perform topological scheduling.

It does NOT detect cycles.

It does NOT own workflow lifecycle state.


Canonical edge direction:

    prerequisite_stage -> dependent_stage


Example:

    A -> B

means:

    B depends on A.
